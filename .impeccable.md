## Design Context

### Users
People managing projects across cloud providers, VPS instances and local or VPN-connected servers. They need an immediate, trustworthy answer to which instances and application services are available.

### Brand Personality
Native, quiet, dependable.

### Aesthetic Direction
Follow Ubuntu GNOME's design language and the current system theme. Use the Shell's panel and popup components, symbolic icons, inherited typography, and Libadwaita preference controls. English and Spanish translations; follow the session language. Status glyphs and service segments use semantic theme colors with GNOME palette fallbacks. No custom fonts, backgrounds or theme overrides.

### Design Principles
- Group projects by provider; reveal services and actions on expansion.
- Always pair status icons with words, including unavailable and stale observations.
- Distinguish instance connectivity from application and dependency health.
- Inherit the desktop theme, text scaling, keyboard navigation and motion behavior.
- Stay read-only: checks never restart, deploy or generate content.
